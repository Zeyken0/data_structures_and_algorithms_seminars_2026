# Sorting Algorithms

Реализация пяти алгоритмов сортировки на C++ с модульными тестами.

## Алгоритмы
- Bubble Sort
- Optimized Bubble Sort
- Insertion Sort
- Selection Sort
- Exchange Sort

## Стек
- C++17
- CMake 3.16+
- Catch2 v2 (vendored)
- clangd / Neovim

## Сборка
\`\`\`bash
cmake -S . -B build
cmake --build build
\`\`\`

## Запуск тестов
\`\`\`bash
./build/tests/sorting_tests
\`\`\`
