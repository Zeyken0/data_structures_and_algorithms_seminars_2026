# Shell and Quick Sort

Реализация двух улучшенных алгоритмов сортировки на C++ с модульными тестами.

## Алгоритмы
- Shell Sort (метод Шелла)
- Quick Sort (быстрая сортировка)

## Стек
- C++17
- CMake 3.16+
- Catch2 v2 (vendored)
- clangd / Neovim

## Сборка
```bash
cmake -S . -B build
cmake --build build
```

## Запуск тестов
```bash
./build/tests/sorting_tests
```
