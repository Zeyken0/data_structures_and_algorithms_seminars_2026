# Структуры и алгоритмы обработки данных — семинары 2026

Работы по семинарам курса «Структуры и алгоритмы обработки данных» (СТАНКИН).
Каждый семинар — самостоятельный CMake-проект на C++17 с модульными тестами
на Catch2 v2 (vendored, в `external/catch2`).

## Структура

| Папка | Тема | Алгоритмы |
|-------|------|-----------|
| [`Семинар_1_ДЗ`](Семинар_1_ДЗ) | Простые сортировки | Bubble Sort, Optimized Bubble Sort, Insertion Sort, Selection Sort, Exchange Sort |
| [`Семинар_2_ДЗ`](Семинар_2_ДЗ) | Улучшенные сортировки | Binary Insertion Sort, Shaker Sort |
| [`Семинар_3_ДЗ`](Семинар_3_ДЗ) | Сортировки | Shell Sort, Quick Sort |
| [`Семинар_4_ДЗ`](Семинар_4_ДЗ) | Внешние сортировки | Двухфазная и однофазная сортировка прямым слиянием, естественное слияние |

## Тесты

Во всех семинарах тесты построены на едином тестовом массиве по варианту 8

```
12, 6, 0, 14, 5, 18, 2, 8   →   0, 2, 5, 6, 8, 12, 14, 18
```

и покрывают граничные случаи: пустой вход, один элемент, отсортированный и
обратный порядок, дубликаты, отрицательные числа, «хвосты» серий, а также
типы `int`, `double` и `float`.

## Сборка и запуск

Каждый семинар собирается независимо:

```bash
cd Семинар_N_ДЗ
cmake -S . -B build
cmake --build build
./build/tests/sorting_tests   # или: ctest --test-dir build --output-on-failure
```
